先说清楚这套东西是什么：

  一个放在你自己 GitHub 账号上的小程序，每 3 小时自动帮你做这些事：
    1. 从 50 个公开节点源抓节点
    2. 每个都真连一下，连不上的扔掉
    3. 按「美国 / 家宽 / 原生」挑出好的
    4. 生成订阅文件，放在一个固定网址上

  你手机上装个 Clash 类 App，把这个网址填进去，
  以后就再也不用管了 —— 节点自动换，网址永远不变。

═══════════════════════════════════════════════
  第 0 步  你需要准备什么
═══════════════════════════════════════════════

  ✓ 一个 GitHub 账号（免费，没有就第 1 步现注册）
  ✓ 一台电脑（Windows 或 Mac 都行，用来上传一次文件）
  ✓ 一部手机，装好 Clash 类 App
  ✓ 全程大约 15 分钟

  关于要不要花钱：全部免费。
  GitHub 的公开仓库跑定时任务是免费的，Pages 托管也是免费的。


═══════════════════════════════════════════════
  第 1 步  注册 GitHub
═══════════════════════════════════════════════

  已经有账号的，跳到第 2 步。

  1. 浏览器打开 https://github.com/signup
  2. 填邮箱 → 设密码 → 起个用户名（英文，记下来，后面要用）
  3. 邮箱收验证码，填进去
  4. 注册完，保持登录状态进下一步

  注意：GitHub 在国内有时打不开。打不开就换个网络
  （手机热点试一次），或者等晚一点再试。


═══════════════════════════════════════════════
  第 2 步  建一个空仓库
═══════════════════════════════════════════════

  1. 登录后，点右上角的「+」，选「New repository」
     （或直接打开 https://github.com/new）

  2. 三个地方要填对：

     ① Repository name（仓库名）
        填 free-node-hub
        （名字随便起，英文、不带空格，后面要用）

     ② 下面两个选项，Public / Private
        必须选「Public」！
        为什么：Private 仓库跑定时任务每月只有 2000 分钟免费额度，
        这个项目每月要用掉约 1400 分钟，快撞顶；
        而且 Private 仓库的网页托管要收费。选 Public。

     ③ 底下的「Add a README file」等三个勾选框
        全部不要勾！保持空仓库。

  3. 点最下面绿色的「Create repository」

  建好后你会看到一个几乎是空白的页面，上面写着
  「Quick setup — if you've done this kind of thing before」。
  这就对了，接着下一步。


═══════════════════════════════════════════════
  第 3 步  把文件传上去
═══════════════════════════════════════════════

  先把下载到的 free-node-hub.zip 解压，你会看到一个叫
  free-node-hub 的文件夹。

  ★ 里面有 2 个是「隐藏」的，Windows 默认看不见：
      .github      （文件夹，装定时任务的）
      .gitignore
  如果按方法 B 拖拽上传，看不到 .github 就传不上去，
  整个自动更新就废了。所以先打开隐藏文件显示：

    Windows 10：打开文件夹 → 顶部「查看」→ 勾上「隐藏的项目」
    Windows 11：顶部「查看」→「显示」→ 勾上「隐藏的项目」
    Mac：在文件夹里按 Command + Shift + .（句点）


  ───── 方法 A：双击脚本上传（推荐，最省事）─────

  Windows：
    1. 打开 free-node-hub 文件夹
    2. 双击 setup.bat
    3. 弹出黑窗口，按提示填两样：
         GitHub 用户名：你第 1 步起的那个
         仓库名：free-node-hub
    4. 回车，等它推上去
    5. 中途可能弹出 GitHub 登录窗口，按提示登录/授权

    如果提示"没装 Git"：
      去 https://git-scm.com/download/win 下载，
      安装时一路点 Next（默认就行），装完关掉黑窗口重新双击。

  Mac：
    1. 打开「终端」（启动台搜"终端"）
    2. 输入：cd 空格，然后把 free-node-hub 文件夹拖进终端窗口，回车
    3. 输入：bash setup.sh 回车
    4. 按提示填用户名和仓库名
    5. 提示要密码时，输入 GitHub 密码（输入时屏幕不显示，正常）

    如果提示没装 Git：
      终端里输入 xcode-select --install 回车，按提示装完再重来。

  看到「上传成功」就对了，跳到第 4 步。


  ───── 方法 B：网页拖拽上传（不装任何东西）─────

  1. 打开你刚建的仓库页面
  2. 点「uploading an existing file」这行蓝字
     （或 Add file → Upload files）
  3. 打开解压出来的 free-node-hub 文件夹（已经显示隐藏文件）
  4. 全选里面的所有东西（Ctrl+A / Command+A），拖进网页的框里
  5. 等文件列表跑完，最下面点绿色「Commit changes」

  ⚠️ 检查一件事：传完后刷新仓库首页，
     应该能看到 .github 这个文件夹。
     看不到就是隐藏文件没显示、漏传了 —— 重新来一次。


═══════════════════════════════════════════════
  第 4 步  开两个开关（不开必定失败）
═══════════════════════════════════════════════

  这两个不设置，跑起来一定报错。耐心点，就两处。

  ───── 开关 1：允许它自己保存文件 ─────

  1. 仓库页面顶部一排标签，点「Settings」（齿轮图标）
  2. 左边列表往下找，点「Actions」→ 再点「General」
  3. 页面拉到最下面，找到「Workflow permissions」
  4. 选上「Read and write permissions」
     （默认选的是 Read repository contents... 那个，要改）
  5. 点旁边的「Save」

  ───── 开关 2：打开网页托管 ─────

  1. 还在 Settings 里，左边列表点「Pages」
  2. 「Source」那里，把下拉框从「Deploy from a branch」
     改成「GitHub Actions」
     （改完不用点保存，它自动生效）


═══════════════════════════════════════════════
  第 5 步  手动跑第一次
═══════════════════════════════════════════════

  定时任务是每 3 小时跑一次，但刚建好不会立刻跑，
  手动点一次，不用等。

  1. 仓库页面顶部，点「Actions」标签
     （第一次进来可能有个按钮让你了解工作流，点一下进去）
  2. 左边列表点「更新节点订阅」
  3. 右边有个灰色下拉「Run workflow」，点开
  4. 里面还有一个绿色按钮「Run workflow」，点它
  5. 刷新页面，会看到一个黄色转圈的条目，说明在跑了

  跑一轮大概 3～6 分钟。

  跑完之后：
    ✓ 图标变成绿色对勾 → 成功，进第 6 步
    ✗ 图标变成红色叉 → 点进去看报错，对照第 10 步

  顺手看一眼结果（推荐）：
    点进那次运行记录，页面最下面有个「Summary」，
    里面会写中文：
      - 状态：已更新订阅
      - 节点数：623
      - 源成功率：38/50
    看到这些就说明一切正常。


═══════════════════════════════════════════════
  第 6 步  拿到你的订阅地址
═══════════════════════════════════════════════

  打开这个网址（把 <用户名> <仓库名> 换成你自己的）：

      https://<用户名>.github.io/<仓库名>/

  例如用户名是 zhangsan，仓库名是 free-node-hub，就是：

      https://zhangsan.github.io/free-node-hub/

  这个页面就是你的面板，上面能看到：
    · 最后更新时间、节点总数、美国 / 家宽 / 原生各多少个
    · 5 个订阅地址，每个后面有「复制」按钮
    · 线路切换按钮（GitHub Pages / jsDelivr / ghproxy / raw）

  第一次打开如果显示"还没有更新记录"，
  等 1～2 分钟（网页托管要发布一下）再刷新。

  ★ 你平时只用其中一个：「完整版」那条。
    点它右边的「复制」，地址就进剪贴板了。


═══════════════════════════════════════════════
  第 7 步  手机导入
═══════════════════════════════════════════════

  先看你用的是什么 App。不知道装什么就装 FlClash（安卓）
  或 Clash Verge（电脑），这两个最省事。

  ───── FlClash / Clash Verge / Mihomo（推荐）─────

  1. 手机上打开面板网页，复制「完整版」地址
     （怎么从电脑传到手机？微信发给自己、或者用笔记 App 都行）
  2. 打开 App → 底部或左边找「配置」/「订阅」/「Profiles」
  3. 点右上角「+」→ 选「从链接导入」/「URL 导入」
  4. 粘贴地址 → 确定
  5. 等它下载完，点一下这份配置卡片，让它变成选中状态
  6. 回到首页，点「代理」/「节点」，选「🚀 节点选择」
  7. 打开浏览器试试能不能上外网

  ───── Stash（iOS）─────

  1. 复制「完整版」地址
  2. Stash → 配置 → 右上角 + → 从 URL 下载 → 粘贴 → 完成
  3. 首页选这份配置 → 启动

  ───── NekoBox（安卓）─────

  1. 复制面板上「sing-box」那一条地址
  2. NekoBox → 左上角三条杠 → 订阅 → 右上角 + → 粘贴
  3. 保存 → 点这条订阅 → 更新一次
  4. 回到主页选节点

  ───── v2rayN（电脑）─────

  1. 复制「base64」那条地址
  2. v2rayN → 订阅 → 订阅设置 → 添加 → 粘贴 → 确定
  3. 订阅 → 更新订阅

  ★ 一定要设「自动更新间隔」为 6 小时
    （大多数 App 默认就是这个，或 24 小时，改成 6 更好）

  ★ 节点名字里的意思：
      🇺🇸 US · 家宽·原生 | Comcast      真住宅 IP，最干净
      🇺🇸 US · 疑似家宽 | Verizon        像住宅，实际是机房
      🇺🇸 US · 机房 | DigitalOcean       普通云服务器
      🎯 原生 IP 分组 = 查出来是当地本土 IP 的
      🏠 美国家宽 分组 = 只有住宅 IP，最少但最好


═══════════════════════════════════════════════
  第 8 步  国内拉不到怎么办（重点看这节）
═══════════════════════════════════════════════

  症状：App 里点更新，报「下载失败 / 格式错误 / 超时」。
  原因：github.io 这个域名在国内经常打不开。
  不是你的项目坏了，换条线路就行。

  ───── 办法 1：换线路（10 秒，先试这个）─────

  1. 打开面板网页（能打开说明网络还行）
  2. 往下滚到「⚡ 加速线路」那一栏
  3. 点「jsDelivr」
  4. 上面 5 个卡片里的地址会变，重新复制「完整版」那条
  5. 回 App 里，编辑那条订阅，把地址换成新的

  还不行就再试「ghproxy」。


  ───── 办法 2：自己搭一条中转（最稳，5 分钟，免费）─────

  这是 Cloudflare 的免费服务，搭好之后你有一个属于自己的
  固定地址，不容易被墙，也不依赖第三方加速站。

  1. 注册 Cloudflare
     打开 https://dash.cloudflare.com/sign-up
     邮箱 + 密码，注册完验证邮箱，登录

  2. 建一个 Worker
     左侧菜单找到「Workers & Pages」→ 点「Create」
     → 选「Worker」→ 起个名字（比如 mysub）→ Deploy
     （它会先给你一段示例代码，不用管）

  3. 换代码
     点「Edit code」/「编辑代码」
     把左边框里的内容全选删掉
     打开项目文件夹里的 tools/worker.js
     用记事本打开，找到这一行（第 21 行，文件顶部不远）：

         const REPO = "你的用户名/你的仓库名";

     改成你自己的，比如：

         const REPO = "zhangsan/free-node-hub";

     注意：中间是斜杠，两边是英文引号，别删分号。
     改完把整个文件内容复制，粘进 Cloudflare 的代码框
     （全部替换）

  4. 保存并部署
     右上角「Deploy」/「部署」
     成功后它会给你一个地址，长得像：
         https://mysub.你的名字.workers.dev

  5. 验证
     浏览器打开：https://mysub.你的名字.workers.dev/clash
     能看到一堆节点配置文字（不是报错页）就成功了。

  6. 填进面板
     回到你的面板网页 →「⚡ 加速线路」→ 点「自建中转」
     → 在输入框里填 https://mysub.你的名字.workers.dev
     → 点「保存」
     然后复制上面卡片里的地址，填进 App。

  以后就用这个地址，永久不变，也不怕 GitHub 打不开。

  ⚠️ 注意 Worker 有个限制：免费版每天 10 万次请求，
     你一个人用一天顶多几十次，完全够。
     但它读的是 GitHub 的文件，所以 GitHub 那边必须能跑通
     （Actions 每 3 小时成功一次就行）。


═══════════════════════════════════════════════
  第 9 步  日常维护（其实没有）
═══════════════════════════════════════════════

  设好之后，你什么都不用做。

  它自己会：
    · 每 3 小时抓一次节点、换掉死的
    · 每天多跑一次兜底
    · 每周日把提交历史压一下（不然仓库会越变越大）
    · 数据出问题时自动保留上一轮，不会把你的订阅搞空

  你偶尔想检查一下的话，看面板最上面那行：
    「最后更新 xxx · 刚刚 / 3 小时前」
  3～6 小时内都正常。超过 24 小时就去看眼 Actions。

  ⚠️ 一个必须知道的事：
     GitHub 规定，公开仓库如果连续 60 天没有任何活动，
     定时任务会被暂停。
     这个项目每 3 小时就自动提交一次，所以不会触发。
     万一真遇到（比如你手动停了很久），
     去 Actions 点一次 Run workflow 就恢复了。

  │   → 免费节点就是这样，寿命几小时到几天。      │
  │     手动在 App 里更新一次订阅，换成新一批。   │
  └──────────────────────────────────────────────┘


═══════════════════════════════════════════════
  附录 A  想加源 / 想改数量
═══════════════════════════════════════════════

  打开 src/config.py（在 GitHub 网页上也能直接改）：
    点开文件 → 右上角铅笔图标 → 改 → 最下面 Commit changes

  常用几项：

    MAX_OUTPUT_NODES = 600
      最终输出多少个节点。嫌多改小（手机加载快），
      嫌少改大（最多别超过 1500，客户端会卡）。

    FETCH_WORKERS = 12
      同时抓几个源。别超过 20。

    FOCUS_COUNTRIES = {"US"}
      想让别国节点也排前面，改成 {"US", "JP", "HK"}

    SOURCES = [...]
      源清单。加一条就是一行，照现有格式抄：
        {"name": "随便起个名", "kind": "clash", "url": "https://..."}
      kind 可选：clash / uri / base64 / singbox / vpngate

    MIN_OUTPUT_NODES = 25
      本轮可用节点低于这个数就不覆盖（保护你的订阅别变空）

  改完会自动触发一轮运行（改了代码算变更）。

═══════════════════════════════════════════════
  最后几句实话
═══════════════════════════════════════════════
