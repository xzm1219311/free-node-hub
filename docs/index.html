📱 怎么导入

Clash Verge / FlClash / Mihomo / Stash（安卓、iOS、电脑）
  1. 复制上面完整版的地址
  2. 打开 App → 订阅 / Profiles → 右上角 + 或「从链接导入」
  3. 粘贴地址 → 确定 → 点一下刚出现的订阅把它启用
  4. 回到首页，节点选择选「🚀 节点选择」，然后开始用
NekoBox / sing-box（安卓）
  1. 复制 sing-box 那一条地址
  2. NekoBox → 左上角菜单 → 订阅 → 新建 → 粘贴 → 保存
  3. 点订阅条目更新一次，然后选节点
v2rayN（只想要链接列表）
  1. 复制 base64 那条地址
  2. v2rayN → 订阅 → 订阅设置 → 添加 → 粘贴
